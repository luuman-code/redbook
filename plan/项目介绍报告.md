## 1. 项目概述

### 1.1 项目简介

**Redbook** 是一个 AI 小红书文案生成工作流系统，通过多智能体协作架构自动化生成小红书内容，包括文案、配图、视频和语音。

- **项目位置**: `C:\Users\LWB\Desktop\redbook\`
- **版本**: 1.3.0
- **已完成 Phase**: 6个阶段

### 1.2 主要功能

| 功能模块 | 说明 |
|---------|------|
| 需求解析 | 解析用户输入，提取产品信息、风格偏好、关键词 |
| 内容规划 | 生成标题、正文、标签、互动引导等文本内容 |
| 图像生成 | 生成配图，支持多种风格 |
| 视频生成 | 生成视频内容（文字转视频/图转视频） |
| 语音合成 | 生成配音/BGM |
| 内容审核 | 敏感词检查、质量评分 |
| 迭代优化 | 根据用户反馈迭代内容 |
| 发布导出 | 导出素材包 |
| Canvas画板 | 可视化编辑和创作工作区 |
| Mode路由 | ML+LLM混合智能模式切换 |

### 1.3 技术栈

| 层级 | 技术 |
|------|------|
| 后端框架 | FastAPI + uvicorn + SQLAlchemy |
| 前端框架 | React 18 + TypeScript + Vite |
| LLM Provider | DashScope (阿里云通义千问)、OpenAI、Anthropic |
| 向量存储 | ChromaDB |
| 关系存储 | SQLite (开发) / PostgreSQL (生产) |
| 异步处理 | asyncio, aiohttp, aiosqlite |
| 配置管理 | JSON Schema |
| 部署 | Docker, Docker Compose |
| 错误监控 | Sentry |

```python
class BaseGateway(ABC):
    """抽象网关基类，包含熔断器和主备切换"""

    # 熔断器配置
    FAILURE_THRESHOLD = 5          # 失败次数阈值
    RECOVERY_TIMEOUT = 60          # 恢复超时（秒）

    # 主备配置
    _primary_provider = None
    _fallback_provider = None
    _using_fallback = False

    def _check_circuit_breaker(self):
        """检查熔断器状态"""
        if self._failure_count >= self.FAILURE_THRESHOLD:
            self._circuit_open_until = time.time() + self.RECOVERY_TIMEOUT
            self._using_fallback = True

    async def _invoke_with_fallback(self, request, invoke_func):
        """主备切换调用"""
        # 先尝试主提供者，失败后切换到备用
```

### 3.4 Mode Router 智能路由

**文件**: `studio/canvas/mode_router.py`

```python
class Mode(Enum):
    DAILY = "daily"       # 日常聊天模式
    PLANNING = "planning" # 任务规划模式

class ModeRouter:
    """ML+LLM混合路由模式切换器"""

    # ML模型：Sentence-Embeddings + Logistic Regression
    # LLM验证：Ollama (qwen2.5:1.5b)

    # 置信度阈值
    HIGH_CONFIDENCE_THRESHOLD = 0.85  # ML直接判定
    LOW_CONFIDENCE_THRESHOLD = 0.5    # LLM回退

    # 训练样本示例
    DAILY = ["你好啊", "今天天气怎么样", "谢谢你的帮助"]
    PLANNING = ["请帮我画一个史蒂夫", "帮我设计一个logo", "生成一张图片"]
```

**路由逻辑**:
```python
# ML高置信度 → 直接返回结果
# ML中等置信度 → LLM验证
# ML低置信度 → LLM回退
if ml_confidence >= 0.85:
    return ml_result
elif ml_confidence >= 0.5:
    return llm_result if llm.confidence > ml.confidence else ml_result
else:
    return llm_result
```

## 11. Mode Router 智能路由

### 11.1 核心实现

**文件**: `studio/canvas/mode_router.py`

```python
class Mode(Enum):
    DAILY = "daily"         # 日常聊天模式
    PLANNING = "planning"   # 任务规划模式

class ModeRouter:
    """ML + LLM 混合路由"""

    HIGH_CONFIDENCE_THRESHOLD = 0.85
    LOW_CONFIDENCE_THRESHOLD = 0.5

    # ML管道：Sentence-Embeddings → Logistic Regression
    # LLM验证：Ollama (qwen2.5:1.5b)

    async def route(self, user_input: str) -> Mode:
        """路由用户输入到对应模式"""
        ml_result = await self._ml_predict(user_input)
        ml_confidence = ml_result.confidence

        if ml_confidence >= self.HIGH_CONFIDENCE_THRESHOLD:
            return ml_result.mode

        if ml_confidence >= self.LOW_CONFIDENCE_THRESHOLD:
            llm_result = await self._llm_verify(user_input, ml_result)
            return llm_result.mode if llm_result.confidence > ml_confidence else ml_result.mode

        return await self._llm_fallback(user_input)
```
